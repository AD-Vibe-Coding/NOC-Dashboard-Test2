# Team Availability Widget — Full Scope (Version 2)

**Version:** v2 (June 5, 2026)

## Executive summary
The Team Availability widget is the operations control panel for **live queue readiness**, **status context (break/meeting)**, **reminder governance**, and **attendance signaling (punch in/out)**.

## Full feature scope
1. Queue visibility
   - In-shift vs in-queue counts
   - Queue-level readiness breakdown
   - Fast identification of members out of queue
2. Break & meeting state
   - Status state across the team
   - Context for capacity balancing
3. Reminder governance
   - Manager pause control
   - Reduced noise during planned meetings
4. Attendance signaling
   - Compact punch in/out with prompted message
   - Slack broadcast under impersonated sender
5. Event traceability
   - Punch/reminder events logged with timestamps

## Team member advantages
- Less manual check-in friction
- Faster updates with fewer tool switches
- Clear personal status and accountability

## Management advantages
- Real-time staffing awareness
- Faster intervention on queue risk
- Lower manual follow-up effort
- Better governance and auditability

## Compared to traditional process
Traditional process relies on chat + spreadsheets + manual follow-up.
This widget provides centralized, live, and structured operations control.

## Recommended KPIs
- In-queue coverage % by interval
- Average response time to under-coverage
- Reminder-to-resolution time
- Break/meeting impact on queue readiness
- Attendance signaling compliance
